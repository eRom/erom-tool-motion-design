# Index des références décortiquées

14 vidéos de motion design, chacune analysée en 4 fichiers :

- `01_GLOBAL_DA_AND_SYSTEM.md` : direction artistique, palette, typo, easing, tempo.
- `02_CHRONOLOGICAL_BREAKDOWN.md` : découpage plan par plan, calé sur la musique.
- `03_FABRICATION_BLUEPRINTS.md` : recettes de code pour reproduire les effets.
- `04_AUDIO_AND_SOUND_DESIGN.md` : structure musicale et bruitages.

Ce sont des exemples pour nourrir l'œil, pas des gabarits. Choisir 1 à 3 références proches de l'intention, en tirer des principes (rythme, contraste, système), ne jamais en recopier une.

Pour choisir : lire ce tableau, puis le `01` des candidats retenus. Ne charger `02` et `03` que pour une recette précise : ce sont les fichiers les plus longs.
