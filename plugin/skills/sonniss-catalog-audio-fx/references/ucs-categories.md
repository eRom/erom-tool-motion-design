# Catégories UCS présentes dans la banque

UCS (Universal Category System) : le début du nom d'un son donne sa catégorie, `CATEGORIESous` (ex. `AMBUrbn` = ambiance urbaine). 329 sons sur 609 en ont une ; les 280 autres se cherchent par le nom et le pack. `--cat` de `search.ts` filtre sur le début du code, donc `--cat AMB` prend toutes les ambiances.

| Préfixe | Famille | Utile en motion pour |
|---|---|---|
| `WHSH` | whooshes | entrées, sorties, mouvements rapides de texte ou de caméra |
| `DSGNRise`, `DSGNBoom`, `DSGNBram`, `DSGNBass`, `DSGNDron`, `DSGNErie`, `DSGNTonl`, `DSGNSrce`, `DSGNMisc` | sons « designés » : montées, impacts graves, braams, drones, textures étranges | tension avant une révélation, impact sur un titre, fond de bande-annonce |
| `MUSCStngr` | stingers musicaux | ponctuer un logo ou une chute |
| `UIClick`, `UIData`, `UIMvmt`, `UIAlert`, `UIMisc`, `BEEPAppl` | interfaces | apparitions d'éléments d'écran, curseurs, notifications |
| `SCIWeap`, `SCIMisc`, `SCIMech`, `SCICmpt`, `ROBTVox`, `ELECEmf` | science-fiction, robots, champs électriques | univers tech, IA, glitchs |
| `EXPLReal`, `EXPLDsgn`, `DESTRCrsh`, `METLImpt`, `METLCrsh`, `WOODImpt`, `GLASBrk`, `FGHTImpt` | explosions, chocs, casse | impacts physiques |
| `AMB…` (`AMBUrbn`, `AMBRoom`, `AMBForst`, `AMBTran`, `AMBInd`…) | ambiances (souvent longues, plus d'une minute) | lit sonore d'une scène, à couper |
| `VEH…`, `TRN…`, `BOAT…` | véhicules, trains, bateaux | passages, démarrages |
| `GUN…`, `WEAP…` | armes à feu, armes blanches | action |
| `WATR…`, `RAIN`, `WIND`, `THUN`, `FIRE…`, `ICE…` | éléments | textures naturelles |
| `FOLY…`, `CLOTH…`, `PAPR…`, `OBJ…`, `TOOL…`, `DOOR…`, `CLOCKTick` | bruitage du quotidien | gestes, objets, tic-tac de compte à rebours |
| `HMNBrth`, `VOX…`, `CRWDWalla` | souffles, voix, foules | présence humaine |
| `ANML…`, `BIRD…`, `CREAMisc` | animaux, oiseaux, créatures | vie, monstres |
| `TOONPop` | cartoon | ton léger |
